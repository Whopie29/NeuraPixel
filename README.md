## 🌌 Overview

**NeuraPixel AI** is a modern AI-powered image generation web application built with Flask and advanced AI models. Type a prompt, pick a model and size, and generate stunning AI-created images — all through a clean, responsive interface with plan-based access tiers.

---

## 🚀 Features

<table>
<tr>
<td width="50%" valign="top">

- 🧠 **AI Image Generation** — create stunning images from text descriptions
- ⚡ **Multiple Models** — support for Flux and Turbo AI models
- 📏 **Flexible Sizing** — custom dimensions and preset sizes

</td>
<td width="50%" valign="top">

- 💳 **Plan-based Access** — Free, Starter, Pro, and Premium tiers
- 🎨 **Modern UI** — dark/light themes with smooth animations
- 📱 **Responsive Design** — works on both desktop and mobile

</td>
</tr>
</table>

## 🧩 Installation

<table>
<tr><td width="6%" align="center"><b>1</b></td><td>

**Clone the repository**
```bash
git clone https://github.com/Whopie29/NeuraPixel.git
cd NeuraPixel
```

</td></tr>
<tr><td align="center"><b>2</b></td><td>

**Install dependencies**
```bash
pip install -r requirements.txt
```

</td></tr>
<tr><td align="center"><b>3</b></td><td>

**Run the application**
```bash
python app.py
```

</td></tr>
<tr><td align="center"><b>4</b></td><td>

**Open your browser**
👉 http://localhost:5000

</td></tr>
